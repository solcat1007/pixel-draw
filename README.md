# 像素画板 (Pixel Draw)

一个简洁的网页像素绘画工具，支持画笔、橡皮、填充等基础绘画功能。

## 功能

- **像素绘画**：在可调节大小的网格上逐像素绘制
- **三种工具**：
  - 画笔：使用当前颜色绘制像素
  - 橡皮：擦除像素（恢复白色）
  - 填充：一键填充同色区域（洪水填充算法）
- **颜色选择**：内置取色器，任意选择颜色
- **可调网格**：支持 8x8 到 64x64 的网格密度
- **清空画布**：一键重置
- **导出 PNG**：将画作保存为 PNG 图片下载
- **中英文切换**：界面支持中文/英文
- **全屏模式**：沉浸式绘画体验

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击颜色圆圈选择画笔颜色
3. 在画布上点击或拖拽进行像素绘画
4. 使用"填充"工具点击封闭区域快速填色
5. 点击 +/- 调整网格密度
6. 点击"导出PNG"保存作品

## 技术栈

纯 HTML/CSS/JavaScript，使用 Canvas API 和洪水填充算法。
