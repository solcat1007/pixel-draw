# 像素画板 (Pixel Draw)

## v2.0 更新（2026）

- **调色板扩展**：24 色调色板 + 自定义取色器 + Shift 点击吸色
- **撤销 / 重做**：每笔一次快照，最多 40 步，`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）
- **PNG 导入导出**：导入图片自动缩放采样到网格，导出保留透明背景
- **网格尺寸调节**：8/16/32/48/64 四档，切换时按比例重采样保留作品
- **一键分享**：优先调用系统分享面板，不支持时回退为下载 PNG
- **隐藏彩虹笔**：按坐标循环取色的彩蛋画笔

**专属彩蛋**：激活彩虹笔或 KONAMI 秘籍，画布角落留下 SOLCAT 金色签名。


一个简洁的网页像素绘画工具，支持画笔、橡皮、填充等基础绘画功能。

## 功能

- **像素绘画**：在可调节大小的网格上逐像素绘制
- **三种工具**：
  - 画笔：使用当前颜色绘制像素
  - 橡皮：擦除像素（恢复白色）
  - 填充：一键填充同色区域（洪水填充算法）
- **颜色选择**：内置取色器，任意选择颜色
- **可调网格**：支持 8x8 到 64x64 的网格密度
- **清空画布**：一键重置
- **导出 PNG**：将画作保存为 PNG 图片下载
- **中英文切换**：界面支持中文/英文
- **全屏模式**：沉浸式绘画体验

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击颜色圆圈选择画笔颜色
3. 在画布上点击或拖拽进行像素绘画
4. 使用"填充"工具点击封闭区域快速填色
5. 点击 +/- 调整网格密度
6. 点击"导出PNG"保存作品

## 技术栈

纯 HTML/CSS/JavaScript，使用 Canvas API 和洪水填充算法。

## 彩蛋秘籍

所有小工具共用同一套彩蛋协议（EGG PROTOCOL v2.0）：

| 秘籍 | 效果 |
|------|------|
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花 + 触发本应用专属彩蛋 |
| 连点页面标题 5 次 | 打开开发者模式面板 |
| 输入 `solcat` 后按回车 | 启用赛博朋克隐藏主题 |
| `Ctrl + Shift + T` | 切换赛博朋克隐藏主题 |
| 打开浏览器控制台 | 查看 SOLCAT ASCII 署名与解锁提示 |

> 提示：每个应用还藏有一个专属彩蛋，见上方 v2.0 更新说明。
